# data/bank — Document & Playbook Bank

Every file you upload or text you paste in any profile is also saved here, so new profiles can attach it
with one click ("Elegir del Banco") instead of browsing your PC again.

- roles/        Position / role descriptions
- cvs/          Professional profiles / CVs
- experience/   Supporting experience / story-bank files
- playbooks/    Playbook templates (default_playbook.md is the built-in default)

Files are stored as extracted text (.md). You can also drop .md/.txt files here by hand.
